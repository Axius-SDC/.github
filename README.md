# Axius-SDC Organization Configuration

This is the `.github` repository for the **Axius-SDC** organization. It contains organization-wide configuration files and community health files that apply to all repositories in this organization.

## Purpose

The `.github` repository is a special GitHub repository that provides default community health files, issue templates, pull request templates, and other configuration files for all repositories within the Axius-SDC organization. When a repository doesn't have its own version of these files, GitHub automatically uses the ones from this repository.

## What's Included

This repository may contain:

- **Community Health Files**: CODE_OF_CONDUCT.md, CONTRIBUTING.md, SECURITY.md, SUPPORT.md
- **Issue Templates**: Templates for bug reports, feature requests, and other issue types
- **Pull Request Templates**: Default templates for pull requests
- **Funding Configuration**: FUNDING.yml for repository sponsorship options
- **Workflow Templates**: Reusable GitHub Actions workflows

## About Axius-SDC

Axius-SDC is focused on semantic data charter development and provides tools and frameworks for working with semantic data models.
